Book My Trip :

Book My Trip is an online travel booking system designed to simplify trip planning. Users can explore destinations, view travel packages, book trips and manage their bookings. The system includes user authentication, booking history, and an admin panel to manage trips, users, and enquiries efficiently.

technologies used :

Frontend : Html-5
           Css-3
           Javascript
           Bootstrap

Backend : Python Programming
          Django Framework 
         
Database : MySQL database
